# 업종별 핵심 지표

업종마다 진짜 중요한 지표가 다르다. 아래 목록에 없는 업종은 가장 가까운 항목을 쓰고
"대체 적용" 사실을 카드에 적는다.

| 업종 | 핵심 지표 | 보조 |
|---|---|---|
| 구독·SaaS | 이탈률(churn), 순매출유지율(NRR), ARR | CAC 회수기간, 총마진 |
| 제조 | 가동률, 재고회전, 단위당 원가 | 설비투자/감가상각 비율 |
| 소매·유통 | 동일점포매출(SSS), 평방피트당 매출 | 재고회전, 점포 순증 |
| 반도체 | 가동률, ASP, 재고일수 | 설비투자 사이클, 수율 |
| 은행 | 순이자마진(NIM), 대손충당금, CET1 | 예대율, 비이자수익 비중 |
| 보험 | 합산비율(combined ratio), 책임준비금 | 투자수익률 |
| 헬스케어·제약 | 파이프라인 단계별 자산, 특허 만료 일정 | R&D/매출, 급여 커버리지 |
| 플랫폼·광고 | MAU/DAU, ARPU, 참여시간 | 광고단가, 테이크레이트 |
| 에너지·원자재 | 생산량, 손익분기 가격, 매장량 대체율 | 헤지 비중 |
| 리츠 | FFO/AFFO, 점유율, 임대료 스프레드 | LTV, 가중평균 만기 |
| 유틸리티 | 규제자산기반(RAB), 허용수익률 | 요금 재산정 주기 |
| 항공·운송 | RPK/ASK, 탑재율, 좌석마일당 비용 | 유가 헤지 |
