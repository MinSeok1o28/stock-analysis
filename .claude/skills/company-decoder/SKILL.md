# 기업 해독기

## 트리거
`<티커> 분석해줘` · `<회사> 어떤 회사야` · `해독해줘` · `요약 카드`

## 1. 먼저 파이프라인을 실행한다

```bash
python3 -m src.pipelines.company_decoder AAPL     # 미국
python3 -m src.pipelines.company_decoder 005930   # 한국 (6자리 종목코드)
```

`reports/cards/<티커>-decoder-<날짜>.md` 가 생성된다. **이 파일이 사실의 근거다.**
여기 없는 숫자를 만들어 쓰지 않는다. 파이프라인이 조립하는 것:

- 재무 골격 5~6년: 매출·YoY·순이익·순이익률·FCF·FCF마진 (한국은 영업이익 추가)
- `연속 증가/감소` 판정, FCF 수익률, 주당 매출
- 이상치 (FCF 3년 평균 대비 ±40%)
- 현재가·시가총액·주식수
- 미국: 10-K Item 1 발췌 2,400자 + 세그먼트 단서 문장
- 확인 필요 목록

## 2. 시장별 차이를 먼저 확인한다

| | 미국 | 한국 |
|---|---|---|
| 재무 | SEC `companyfacts` (키 불필요) | OpenDART `fnlttSinglAcntAll` (무료 키) |
| 본문 | 10-K Item 1 **자동 추출** | **미구현** — DART 뷰어 링크로 안내 |
| 핵심 지표 | 순이익률 중심 | **영업이익률 중심** |
| 단위 | B (10억) | 조 |

한국 종목은 본문이 없으므로 "돈 버는 구조"를 카드에 지어내지 말고,
DART 링크를 제시하며 **직접 확인이 필요하다고 적는다.**

## 3. 자산유형을 확인한다

카드 상단의 `평가 잣대`를 본다. `fundamental` 이 아니면 **이 스킬을 계속 쓰지 말고**
콕핏으로 보낸다. 지수·섹터 ETF 는 지수 총계로, 원자재 ETF 는
`models.AssetType.alt_metrics`(실질금리·달러 방향)로 봐야 한다.

## 4. 해석을 얹는다 — 여기부터가 사람 몫

파이프라인은 사실만 조립한다. 다음은 카드를 읽고 작성한다:

1. **돈 버는 구조** — Item 1 발췌를 읽고 mermaid 다이어그램으로. 한국은 생략하고 링크 제시.
2. **매출 분해** — 카드의 `세그먼트·지역 단서` 문장을 근거로 서술한다.
   **정확한 수치는 companyfacts 에 차원 축이 없어 못 가져온다** — 숫자를 지어내지 말고
   "10-K 세그먼트 주석에서 확인 필요"로 남긴다.
3. **업종별 핵심 지표** — `reference/sector-metrics.md` 참조. 업종이 목록에 없으면
   가장 가까운 것을 쓰고 "대체 적용" 사실을 적는다. 지표 값 자체는 대개 카드에 없으므로
   본문 발췌로 뒷받침되는 것만 쓴다.
4. **더 파볼 지점 3개 이내** — 투자 의견이 아니라 "무엇을 더 봐야 하는지".

## 5. 출력

카드 파일을 그대로 보여주되, 위 해석을 `## 돈 버는 구조` 와 `## 더 파볼 지점` 에 채운다.
`[사실]`/`[해석]` 표기를 유지한다. 카드의 `## 확인 필요` 절을 지우지 않는다.
